# Radar System

## Overview

All consoles that display spatial information (Helm, Weapons, Science) use a single unified radar system. Each radar instance is configured with a range and a tag filter. The system renders all entities whose tags intersect the filter, within the configured range.

## Configuration

Radar instances are defined per-console in the ship entity TOML:

```toml
[helm.radar]
range = 500.0
shows = ["asteroid", "ship", "torpedo", "station", "debris"]

[weapons.radar]
range = 800.0
shows = ["ship", "station", "torpedo"]

[science.radar]
range = 5000.0
shows = ["ship", "station", "asteroid_field", "region"]

[science.system_chart]
range = 50000.0
shows = ["star", "planet", "asteroid_field"]
```

## Power Scaling

- **Science radar range** scales with Science power allocation via the power multiplier table (`[science.power_multipliers]`). Base range × multiplier = effective range.
- **Helm and Weapons radar range** are fixed regardless of power allocation.

## Region Effects

- If the ship is inside a `radar_dampening` region entity, an additional range multiplier is applied on top of any power scaling. Configurable per region entity.

## Asteroid Fields

- Asteroid fields (`asteroid_field` tag) render as a donut-shaped ring at their inner/outer orbital radii on any radar that includes the `asteroid_field` tag.
- Individual asteroids render as point contacts on radars that include the `asteroid` tag, within their spawned range.

## Targeting

- Science and Weapons each maintain an independent target, selected by tapping an entity on their radar.
- The Science target is highlighted on the Weapons radar as a visual suggestion — advisory only, no mechanical coupling between the two.
- Helm radar does not support targeting.

## Entity Tags (initial set)

| Tag | Used By |
|---|---|
| `star` | System chart |
| `planet` | System chart |
| `asteroid` | Helm radar |
| `asteroid_field` | Science radar, system chart |
| `ship` | All radars |
| `player` | Combined with `ship` for player vessel |
| `enemy` | Combined with `ship` for enemy vessels |
| `station` | Science radar, Weapons radar |
| `torpedo` | Helm radar, Weapons radar |
| `debris` | Helm radar |
| `comms_contact` | Comms contact list |
| `region` | Science radar (optional) |

Entities can have multiple tags. New tags can be added in TOML without changing Rust code.
