# Science Console

The Science console has two tabs, both using the unified radar system (see Radar System doc).

## Tab 1: Long-Range Radar

- Shows entities with tags configured in `[science.radar]` in the ship entity config (e.g. ships, stations, asteroid fields, regions).
- Asteroid fields appear as a donut-shaped ring at their inner/outer orbital radii.
- Science can target an entity by tapping it. The target is highlighted on the Weapons radar as a suggestion — this is advisory only, no mechanical coupling.
- The long-range radar view can be sent to the viewscreen.
- Radar range is affected by Science power allocation (power multiplier applied to base range from ship config).
- Radar range is also affected by `radar_dampening` region entities (range multiplier applied if ship is inside such a region).
- Shows current shield status (fore/aft/port/starboard HP).

## Tab 2: System Chart

- A second radar instance configured with a very large range and navigation-focused tag filter (e.g. `["star", "planet", "asteroid_field"]`).
- Shows: star, planets, asteroid field rings, ship position.
- Non-interactive for targeting (navigational view only).
- This can be sent to the viewscreen.

Both tabs share the same underlying radar rendering system — they differ only in their configured range and tag filter.

## Impulse Drive Control

- Science can cancel an active impulse charge from their console.
- The impulse button is on the Helm console (see Helm). Science has cancel-only authority.

## Configurable Values (in ship entity config)

- Long-range radar range (`[science.radar] range`)
- System chart range (`[science.system_chart] range`)
- Tag filters for both radar instances
- Power multiplier table (`[science.power_multipliers]`)
- Impulse speed multiplier, charge time (in ship root config)
- Shield HP, regen rate, offline duration (`[shields]`)

All numbers should be configurable in the ship entity TOML.
