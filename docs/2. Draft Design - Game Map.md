# Game Map

Each solar system is defined by a TOML file. The map describes static world geometry — things that exist regardless of which scenario is active.

## Loading

- The default map is hardcoded at startup.
- The map file declares a `default_scenario` it always loads on top of itself. This is where fixed world furniture lives (space stations, patrolling ships, etc.).
- Additional scenarios can be layered on during play by other scenarios or entities.
- Entity files referenced by the map are declared as inline path lists and preloaded before gameplay begins.

```toml
default_scenario = "scenarios/default.toml"
```

## Star

```toml
[[star]]
radius = 5000.0
colour = "#FFF4E0"
position = [0.0, 0.0, 0.0]
tags = ["star"]
```

## Planets

Static at their orbital position (no real-time orbit for now).

```toml
[[planet]]
radius = 800.0
colour = "#3A7BD5"
orbital_radius = 20000.0
position = [20000.0, 0.0, 0.0]  # absolute position, calculated from orbital_radius
tags = ["planet"]
```

## Asteroid Fields

Asteroid fields are a persistent entity with a known position (inner/outer radii), used for long-range radar display (shown as a donut ring). Individual asteroids are spawned lazily as the ship approaches — spawning is deterministic and seeded.

- Destroyed asteroids are tracked and not respawned.
- Damaged (but not destroyed) asteroids are not tracked.

```toml
[[asteroid_field]]
tags = ["asteroid_field"]
inner_radius = 8000.0
outer_radius = 12000.0
density = 0.4

# Entity files to preload before gameplay
asteroid_types = [
    "entities/asteroid_small.toml",
    "entities/asteroid_large.toml"
]

# Cosmetic only — no hull integrity, never destroyed
cosmetic_asteroid_types = [
    "entities/asteroid_cosmetic.toml"
]
```

## Spawn Positions

Map anchors can be declared and referenced by name in scenario spawn entries:

```toml
[anchors]
station_zone = [15000.0, 0.0, 3000.0]
patrol_start = [10000.0, 0.0, -2000.0]
```

Scenario spawn positions can be:
- **Absolute**: `position = [1000.0, 0.0, -500.0]`
- **Named anchor**: `position = "station_zone"`
- **Entity-relative**: `position = { entity = "$station", offset = [100.0, 0.0, 0.0] }`
