# Region Entities

## Overview

Region entities are invisible trigger volumes in space. They have a position and radius but no visual representation during gameplay (invisible to the crew). They are used by the scenario system for trigger conditions and by ship systems for environmental effects.

## Entity Config

```toml
tags = ["region", "blocks_impulse"]
position = [5000.0, 0.0, -2000.0]
radius = 1500.0

# Only applied if tagged "radar_dampening"
radar_range_multiplier = 0.4

# Only applied if tagged "damage_zone"
damage_per_second = 5.0
```

## Tags

| Tag | Effect |
|---|---|
| `region` | Base tag, identifies the entity as a region volume |
| `blocks_impulse` | Cancels an active impulse charge and prevents new charges while the ship is inside |
| `radar_dampening` | Applies a `radar_range_multiplier` to Science radar range while the ship is inside |
| `damage_zone` | Applies `damage_per_second` hull damage to the ship while inside (bypasses shields) |

Region entities can have multiple effect tags (e.g. a nebula could be both `radar_dampening` and `damage_zone`).

## Trigger Integration

Region entities can be referenced by the `on_entered_region` trigger condition. The region must have an ID for this:

```toml
id = "forbidden_zone"
tags = ["region", "blocks_impulse"]
position = [5000.0, 0.0, -2000.0]
radius = 1500.0
```

```toml
[[trigger]]
condition = "on_entered_region"
entity = "forbidden_zone"
actions = [
    { load_scenario = "scenarios/warning_broadcast.toml" }
]
```

## Spawning

Region entities are spawned by scenarios (including the default scenario) like any other entity. They are owned by their spawning scenario and despawn when the scenario unloads (unless given a graceful exit behaviour, which for a static volume is unusual).
