Files to define what an entity is, based on a basic type:

Asteroid 
- size range - min to max radius
- colour list - list of colours for the surface to be
- hull integrity points

Ship
- size - radius and length of capsule
- speed values - max forward, max reverse, acceleration, deceleration, turn speed
- total hull integrity points, repair rate, repair cooldown
- phaser damage, phase colour, phaser cooldown
- helm radar range
- weapons console radar range
