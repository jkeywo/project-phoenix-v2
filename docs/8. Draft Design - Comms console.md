# Comms Console

The Comms console handles crew communication with the game world and tracks mission objectives.

## Incoming Messages

- Scenarios trigger incoming messages from entities (stations, enemy ships, etc.) via comms scripts defined in the scenario TOML.
- Incoming messages appear in a message list on the Comms console.
- Messages can be routed to the viewscreen so the whole crew can see them.

## Responses

- The Comms operator selects from predefined response options (not free-text).
- Selecting a response can trigger scenario events (e.g. accepting a distress call loads a rescue scenario).
- Response options are defined in the scenario's comms script.

## Contact List

- Lists all entities currently tagged `"comms_contact"` (stations, certain ships, etc.).
- Comms operator can select a contact to initiate available interactions.

## Objectives Panel

- Displays current mission objectives from all active scenarios.
- Objectives are ordered: mandatory first, optional below.
- Each objective shows its status: active, completed, or failed.
- Completed and failed objectives remain visible until the Comms operator presses the **Clear** button, which removes all completed/failed objectives from the list in one action.
- Scenarios add, complete, and fail objectives via trigger actions (see Scenario File doc).

## Viewscreen Integration

- Comms can send incoming messages to the viewscreen.
- The long-range radar and system chart (Science console) can also be sent to the viewscreen.
