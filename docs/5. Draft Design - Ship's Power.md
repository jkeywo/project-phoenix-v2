# Ship's Power

## Overview

Engineering adjusts power distribution across three consoles: Helm, Weapons, and Science. Power allocation affects each console's performance and the ship's auxiliary battery charge.

## Power Points

- The ship has 6 base power points to distribute across Helm, Weapons, and Science.
- Each console must have between 1 and 4 points assigned.
- 2 points is the baseline (normal performance) for any console.

## Engineering UI

- Increment (+) and decrement (−) buttons per console on the Engineering console.
- The + button is disabled when total allocated points = 6 (or battery cap is reached).
- The − button is disabled when a console is already at 1 point.
- Only Engineering can see which consoles are damaged and need repair. Each console has its own repair button — Engineering must communicate to the relevant operator to press it.

## Power Effects Per Console

- **Helm**: affects movement values (speed, acceleration, turn rate) and repair button speed.
- **Weapons**: affects phaser/torpedo damage and repair button speed.
- **Science**: affects shield regeneration rate, long-range radar range, and repair button speed.

Effects scale via a lookup table per console defined in the ship entity config (see Entity Config Files doc).

## Auxiliary Battery

- Provides up to 2 additional power points beyond the 6 base points (total max 8 allocated).
- Battery has a configurable capacity.
- Charge/discharge rate is determined by a rate table indexed by total allocated points (3–8):

```toml
[battery]
capacity = 100.0
# rates[0] = 3 points allocated, rates[5] = 8 points allocated
# Positive = recharge per second, negative = discharge per second
rates = [6, 5, 4, 2, -2, -6]
emergency_threshold = 25.0  # % charge before Engineering regains control after exhaustion
```

- Allocating fewer than 6 base points results in idle power, which accelerates battery recharge (reflected in the rate table at low totals).

## Battery Exhaustion

- If the battery runs flat:
  - All consoles are immediately forced to 1 power point each (emergency power).
  - Engineering's increment/decrement buttons are locked.
  - Battery begins recharging at the rate for 3 total allocated points (maximum recharge rate).
  - Once battery charge reaches the configurable `emergency_threshold` (e.g. 25%), Engineering regains full control.

## Configurable Values (in ship entity config)

- Power multiplier lookup tables per console (`[helm.power_multipliers]`, `[weapons.power_multipliers]`, `[science.power_multipliers]`)
- Battery capacity, rate table, emergency threshold (`[battery]`)

All numbers should be configurable in the ship entity TOML.
